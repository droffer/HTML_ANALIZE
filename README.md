# HTML Syntax & Structure Analyzer (C++)

Консольный анализатор синтаксиса и структуры HTML-документов, написанный на C++. Проект выполняет синтаксический разбор файлов, проверяет парность и вложенность тегов с помощью стек-анализа, валидирует имена тегов и атрибутов, а также генерирует отчеты об ошибках с подробными рекомендациями по их исправлению.

## 🚀 Основные возможности

* **Валидация вложенности тегов:** Отслеживание корректного порядка закрытия тегов с использованием стековой структуры (`std::vector` / `tagsStack`).
* **Точное позиционирование ошибок:** Определение строки и столбца исходного файла с корректной обработкой многобайтовых символов UTF-8.
* **Поддержка специфики HTML:**
  * Учёт самозакрывающихся (одиночных) тегов (`<br>`, `<img>`, `<meta>`, `<input>` и др.).
  * Игнорирование комментариев (`<!-- ... -->`) и деклараций (`<!DOCTYPE ... >`).
  * Обработка кавычек внутри тегов для предотвращения ложных срабатываний.
* **Проверка синтаксиса:**
  * Валидация имён тегов и атрибутов на соответствие допустимым символам.
  * Детекция незакрытых угловых скобок (`>`).
  * Фиксация повторного открытия синтаксических блоков (`<p>`, `<li>`, `<html>` и др.) без закрытия предыдущих.
* **Формирование отчётов:**
  * Вывод найденных ошибок с пошаговыми инструкциями по исправлению в консоль.
  * Извлечение чистого текста без разметки в файл `output.txt`.
  * Экспорт детализированного лога ошибок в файл `errors.txt`.
* **Защита данных:** Проверка на существование и запрос подтверждения перезаписи итоговых файлов.

## 🛠 Сборка и запуск

### Требования
* Компилятор C++ с поддержкой C++11 или выше (GCC, Clang, MSVC)
* CMake 3.10+ (опционально) или прямая компиляция через CLI

### Сборка через GCC / Clang

```bash
g++ -std=c++11 -O2 main.cpp -o html_analyzer
